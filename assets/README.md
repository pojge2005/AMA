# Academy Assets

This directory contains approved visual assets for the AMA public website.

## Required assets

- `brand/ama-logo.jpg` — original Academy of Martial Arts, Nagpur logo.
- `events/annual-camp-2026.jpg` — Annual Martial Arts Camp 2026 poster.

## Usage rules

- Preserve the academy logo artwork unchanged.
- Use the logo in the public website header, footer, and appropriate academy identity areas.
- Use the camp poster in the Events section.
- Do not replace either asset with generated artwork.
- Keep optimized display copies separate from original source files when both are available.

The binary image files are not included by this documentation commit; they must be added from the supplied image files.
